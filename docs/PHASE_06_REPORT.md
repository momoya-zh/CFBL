### 3.1 实验结论与机理分析
1. **课本 DIP 预处理有效**：在无超分模型介入下，仅加入中值滤波与 CLAHE（`B_dip_only`）即相比 Baseline 将 Test mIoU 提升 `+0.84%`、Dice 提升 `+0.85%`、Recall 提升 `+2.00%`。
2. **自训超分显著增强超声病灶边界特征**：`C1_srcnn_only` 与 `C2_espcn_only` 分别将 mIoU 提升 `+3.51%` 与 `+2.38%`，Dice 提升至 `0.7108` 与 `0.7052`。
3. **SR + 形态学后处理协同最优**：在 `C1_srcnn_only` 基础上施加形态学开闭运算与最大连通域提取（`C1 + Morph`），Test mIoU 达到全场最高 **`0.6187`**（较 Baseline 提升 **`+4.08%`**），Pixel Accuracy 达到 **`0.9496`**，Precision 由 `0.7540` 提升至 `0.7842`。
4. **消融发现（重要机理观察）**：若在超分重建后直接叠加高强度 CLAHE（`D1 / D`），会放大超声高频斑点纹理噪声，使模型 Precision 升高（`0.7867`）但 Recall 下降（`0.6455`），说明医学超声场景中**先超分恢复结构边缘 + 形态学后处理去伪影**比“超分后强直方图拉伸”更适配。
